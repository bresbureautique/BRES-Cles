===== CHECKPOINT_R71.txt =====
BRES CLÉS — CHECKPOINT V2.28 TEST R71

Objet : invalider immédiatement les résultats locaux lorsqu’un autre onglet ou une autre fenêtre modifie la base étalon partagée.

Défaut reproduit en R70 :
- localStorage est partagé entre les onglets/fenêtres de même origine ;
- les écritures faites dans l’onglet courant invalidaient correctement les correspondances ;
- une modification ou un effacement de la base depuis un autre onglet déclenchait un événement storage, mais R70 ne l’écoutait pas ;
- une correspondance et une décision déjà affichées pouvaient donc rester visibles alors qu’elles avaient été calculées avec l’ancienne base.

Correctif R71 :
- écoute dédiée de l’événement navigateur storage ;
- changement de la clé de base étalon : invalidation immédiate des correspondances et décisions dépendantes de la base locale ;
- localStorage.clear() reçu depuis un autre contexte : même invalidation ;
- les autres clés de stockage sont ignorées ;
- l’intégrité de la base persistée est recontrôlée après le changement externe ;
- la géométrie des photos reste disponible : l’utilisateur doit seulement relancer la comparaison.

Test ajouté : LOCAL_STORAGE_EXTERNAL_CHANGE_GUARD_TEST_R71.
Catalogue : 5 103 références uniques attendues ; les 10 morceaux catalogue doivent rester bit-identiques à R40/R70.
Sécurité : V2.27 reste stable sur main. R71 reste uniquement une version de test sur la branche v2.28-test-r1.
