===== CHECKPOINT_R78.txt =====
BRES CLÉS — CHECKPOINT V2.28 TEST R78

Objet : empêcher une annulation du sélecteur de fichier ou une sélection vide d’invalider silencieusement un import de base étalon déjà en cours.

Défaut reproduit en R77 :
- le gestionnaire onchange incrémentait importFileEpoch avant de vérifier qu’un fichier existait réellement ;
- si un environnement remontait un changement avec files vide, l’import actif devenait obsolète puis quittait par stopStaleImport ;
- aucun nouvel import ne prenait le relais et le statut « Import de … en cours… » pouvait rester affiché alors qu’aucune opération ne pouvait encore aboutir.

Correctif R78 :
- la présence réelle de input.files[0] est vérifiée avant toute incrémentation de importFileEpoch ;
- une sélection vide devient un no-op et n’annule pas l’import actif ;
- l’événement cancel du sélecteur est traité explicitement comme un no-op, conformément au comportement attendu des navigateurs modernes ;
- les gardes R75/R76/R77 restent inchangées pour les vrais nouveaux fichiers, les écritures concurrentes, les erreurs et le réessai immédiat ;
- aucun changement des 10 morceaux catalogue.

Test ajouté : LOCAL_DB_IMPORT_PICKER_CANCEL_GUARD_TEST_R78.
Catalogue : 5 103 références uniques attendues ; les 10 morceaux doivent rester bit-identiques à R40/R77.
Sécurité : V2.27 reste stable sur main. R78 reste uniquement une version de test sur v2.28-test-r1.
