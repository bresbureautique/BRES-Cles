# CAT-R371 : revue géométrique du risque OCR (6 novembre 2026)

**Catalogue indépendant. Aucun changement canonique, aucune fusion dans main.**

Les 10 fragments originaux comprennent 5 103 lignes, chacune avec 12 colonnes. Le nouveau rapport examine 393 paires de confusion théorique (68 OCR / 325 frappe) pour prioriser uniquement la **revue manuelle**. Il calcule des distances de longueur et largeur, une différence RMS sur 72 points normalisés et le nombre de bits différents du masque. Ces métadonnées **ne** prouvent **ni** une équivalence physique, **ni** le fabricant, **ni** l'efficacité d'une reconnaissance réelle.

Script de reproduction : `cat_r371_repro_minimal.py`, à exécuter sur les fichiers catalogue décompressés du checkpoint R369/R371 et le ledger `snapshots/CAT-R363/CAT_R363_PAIR_REVIEW_LEDGER.csv`. Résultats : 9/9 contrôles d'audit + 10/10 contrôles indépendants, 68 paires OCR non vérifiées. Toutes les données d'audit détaillées, le CSV et le manifeste SHA-256 sont présents dans l'archive CAT-R371, dont l'empreinte est enregistrée dans `CAT_R371_GITHUB_PROOF.json`.
