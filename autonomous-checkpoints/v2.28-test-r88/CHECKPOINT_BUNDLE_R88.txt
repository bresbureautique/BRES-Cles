CORRECTIF R88
La file Promise locale enveloppe toujours les mutations du document. Le Web Lock exclusif reste utilisé entre onglets participants lorsqu’il fonctionne. Si l’acquisition échoue avant entrée dans le callback, l’action se replie vers la file locale et reste protégée par setDBIfRawUnchanged().
