===== CHECKPOINT_R67.txt =====
BRES CLÉS — CHECKPOINT V2.28 TEST R67

Objet : empêcher qu’une double activation de l’apprentissage local enregistre deux fois exactement la même prise et surpondère artificiellement une référence.

Défaut reproduit en R66 :
- lorsque currentSig était déjà calculée, deux activations rapides de « Enregistrer les 2 photos actuelles comme étalon » pouvaient exécuter deux écritures successives ;
- chaque écriture ajoutait la même signature dans rec.samples ;
- la même prise pouvait donc compter deux fois parmi les cinq échantillons conservés pour une référence.

Correctif R67 :
- ajout d’une garde teachSaveInProgress pendant une opération d’apprentissage ;
- désactivation temporaire du bouton pendant l’opération ;
- calcul d’une empreinte géométrique canonique de la signature avant insertion ;
- une signature déjà présente n’est plus ajoutée une seconde fois ;
- une prise réellement différente reste acceptée ;
- une modification réelle de l’épaisseur reste enregistrable même si la géométrie est identique ;
- un doublon sans autre changement ne réécrit pas la base et n’invalide pas inutilement les résultats ;
- ajout du test LOCAL_TEMPLATE_DUPLICATE_GUARD_TEST_R67 avec reproduction du défaut R66 puis validation du correctif R67.

Catalogue : 5 103 références uniques attendues ; les 10 morceaux de données catalogue restent strictement inchangés par rapport à R40/R66.
Sécurité : V2.27 reste stable sur main. R67 reste uniquement une version de test sur la branche v2.28-test-r1.
