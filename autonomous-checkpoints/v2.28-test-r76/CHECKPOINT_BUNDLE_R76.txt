===== CHECKPOINT_R76.txt =====
BRES CLÉS — CHECKPOINT V2.28 TEST R76

Objet : permettre un réessai immédiat du même fichier JSON après un import terminé, échoué ou annulé sans affaiblir les gardes de concurrence.

Défaut reproduit en R75 :
- le champ <input type=file> conservait le fichier choisi après la fin de l’import ;
- les navigateurs ne redéclenchent généralement pas l’événement change quand l’utilisateur choisit exactement le même fichier déjà sélectionné ;
- après un échec JSON, une erreur de stockage ou une annulation rendue obsolète par une modification plus récente, l’utilisateur pouvait donc être obligé de choisir un autre fichier avant de pouvoir réessayer le bon.

Correctif R76 :
- ajout d’une notion de propriété de la sélection d’import ;
- après succès, erreur ou annulation devenue obsolète, la sélection est vidée uniquement si elle appartient encore à l’import concerné ;
- un ancien import ne peut jamais vider un fichier plus récent choisi pendant sa lecture ;
- les gardes importFileEpoch + localTemplateEpoch de R75 restent inchangées avant toute écriture.

Test ajouté : LOCAL_DB_IMPORT_RETRY_GUARD_TEST_R76.
Catalogue : 5 103 références uniques attendues ; les 10 morceaux catalogue doivent rester bit-identiques à R40/R75.
Sécurité : V2.27 reste stable sur main. R76 reste uniquement une version de test sur la branche v2.28-test-r1.
