===== CHECKPOINT_R74.txt =====
BRES CLÉS — CHECKPOINT V2.28 TEST R74

Objet : empêcher toute publication tardive d’une analyse commencée avant une modification de la base locale d’étalons.

Défaut reproduit en R73 :
- un changement/import/enregistrement de la base locale effaçait bien les résultats déjà affichés ;
- mais invalidateLocalTemplateDependentResults() ne changeait pas identificationEpoch ;
- une analyse géométrique, une lecture OCR ou un apprentissage déjà en attente pouvait donc encore considérer son jeton comme courant et republier après l’invalidation.

Correctif R74 :
- toute invalidation liée à la base locale avance désormais identificationEpoch avant de modifier l’interface ;
- les garde-fous asynchrones existants d’analyse, OCR et apprentissage voient immédiatement leur ancien jeton comme périmé ;
- currentSig peut rester disponible car les photos n’ont pas changé, mais aucun travail démarré avec l’état précédent ne peut publier sans nouvelle action utilisateur ;
- import local, écriture d’un étalon et événement storage externe passent tous par la même protection.

Test ajouté : LOCAL_TEMPLATE_ASYNC_INVALIDATION_GUARD_TEST_R74.
Catalogue : 5 103 références uniques attendues ; les 10 morceaux catalogue doivent rester bit-identiques à R40/R73.
Sécurité : V2.27 reste stable sur main. R74 reste uniquement une version de test sur la branche v2.28-test-r1.
