BRES CLÉS — CHECKPOINT V2.28 TEST R83

Objet : borner la capacité de la base étalon locale et la taille d’un import avant lecture, sans modifier le catalogue.

Défaut reproduit en R82 :
- une référence importée pouvait être arbitrairement longue tant que sa structure restait valide ;
- un JSON pouvait demander un nombre excessif d’étalons et gonfler mémoire/localStorage ;
- le navigateur lisait entièrement le fichier avant toute limite de taille.

Correctif R83 :
- référence normalisée limitée à 64 caractères ;
- référence brute limitée à 128 caractères ;
- base locale limitée à 2 000 références ;
- fichier d’import limité à 8 Mio, contrôlé avant file.text() ;
- diagnostics distincts et saisie d’apprentissage alignée sur les mêmes bornes ;
- aucun changement des 10 morceaux catalogue.
